# Security

This module shells out to `claude --help` (or whatever `Set-ClaudeHelpProvider` injects) and parses text. It does not send telemetry and does not handle credentials.

Report vulnerabilities via GitHub Security Advisories on this repository:

https://github.com/YoraiLevi/pwsh-claude-completion/security/advisories/new

Do not open a public issue for an exploitable parser / code-injection report.
